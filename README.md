# ReturnKeyboard
A new new new mechanical keyboard. My 12th grade capstone project. 



### Software
- See [this repo](https://github.com/DisguisedAxolotl/returnkeypadsoftware)
- All code is currently written in CircuitPython for an Adafruit Feather ESP32-S3. It should run on any feather board after changing some pin definitions.
- This is for the Larchmont Charter Schools test frontend and is subject to breaking change without warning. 

### Documentation
- See [my Capstone Website](https://sites.google.com/larchmontcharter.org/jasperhalkowich/)
- There is not yet any documentation available for using the keyboard

### Hardware
- BOM: (this is very rough)
  - 1200 mAh battery from Adafruit
  - Adafruit Feather RP2350
  - Waveshare RGB LCD module
  - ~20 Kailh Choc V2 Hotswap sockets
  - ~20 diodes
  - ~20 kailh choc switches
  - ~20 SK2360 Mini-E Addressible RGBLEDs
- Circuit Boards: See [this repo](https://github.com/DisguisedAxolotl/Keyboard-return)
  - Note: Although the readme here says QMK is available, I haven't yet set it up. This is left as an exercise to the reader. You might look for another more polished project first though.
